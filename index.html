Introduction

Hypertext Transfer Protocol (HTTP) is an application-layer protocol that enables communication between web browsers and servers.

Key Terms

  • HTTP: Hypertext Transfer Protocol.
  • Client: A device or application requesting resources from a server.
  • Server: A system that processes requests and returns responses.
  • URL: The address used to locate a resource on the web.
  • HTTPS: HTTP communication protected using TLS encryption.
